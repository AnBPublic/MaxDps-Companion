## 4. Design decisions

Publishing: branch `v3.5-class-browser` from `v3/base`, push, PR to master (master stays v1.3.9 untouched).

Toggle SSOT ("app wins"): app pushes toggle mask over ChatCommander `/mdb` at Start + on change, only out of combat. Bridge publishes effective mask in reserved wire cell (additive, presence bit, checksummed). In-game panel becomes read-only mirror + red "blocked by app/addon" badge. Remove silent "addon OFF wins" veto.

Verification bar: only verified ids auto-fire; unverified greyed "needs verification".

Wire: prefer no new wire. Bridge rotates all ready/bound/policy-eligible candidates per tick, filtering neverAutomatic+held; companion de-duplicates. Architect gates whether additive Ext3 needed.
