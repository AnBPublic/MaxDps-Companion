# Companion artwork

The Ma monogram master was generated with the built-in imagegen tool on 2026-11-20, using the Tactara companion icon as a style reference. No upstream addon or game artwork is included.

Run tools/Build-Icon.ps1 to regenerate the transparent 256 px PNG, nine-size Windows ICO (16, 20, 24, 32, 40, 48, 64, 128, 256 px) and macOS ICNS. Application projects consume the generated icons for executable, title bar and tray branding.

Generation prompt:

Use case: logo-brand. Windows app icon matching the Ta and Te companion family: front-on deep charcoal navy rounded square tile, thin luminous colored inset rim, large bold clean geometric sans-serif monogram centered across 65% width, subtle bevel and restrained soft illumination. MaxDPS Companion Retail identity: violet purple inset rim and pale luminous lavender lettering. Text verbatim "Ma", uppercase M lowercase a, absolutely no other text. Square canvas, tile fills canvas with small transparent outer margin; transparent outside rounded tile. Crisp legible at 16px. No ornaments, scenery, mockup, watermark. Match provided reference tile geometry and typography weight.
