protocol: v5 core 35 cells + ADDITIVE Ext2 40-cell block (bridge 3.0.0). The
          v5 core is unchanged: 8 slots incl. Mobility/SelfHeal; raw 24-bit
          spell ids; vitals / cast / target / range / buff / class-spec sensor
          block; additive cell 31 G = HP-curve urgency, cell 31 B bit0 =
          catalog gap-fill source, cell 32 B = stagger urgency (bridge 2.3);
          cell 33 B bit1 = self-buff probe block valid (bridge 2.7). Ext2 adds
          cell 35 (HP-curve colour), cells 36-38 (second distinct ready+bound
          self-heal slot), cell 39 (Ext2 checksum, scope = cells 36-38 only),
          presence bits cell 33 B bit2 EXT2 / bit3 HP CURVE, and the SelfHeal2
          range tri-state in cell 28 B bits0-1. The v5 checksums (cells 10, 34)
          keep covering their original ranges. The wire version nibble STAYS
          5, so older companion exes still decode the 35-cell prefix (they
          ignore the extension) and old 35-cell addons still drive the v3
          companion (bit2=0 → Ext2 ignored). Zero means UNKNOWN and the policy
          keeps its documented fail-open.

v2.7:     self-buff tri-state. GetSlotBuff returns 1/0/nil (ran / none /
          failed-or-secret); WriteBuffs clears the block-valid bit when ANY
          probe degraded, so a failed aura probe can never masquerade as "buff
          absent". A pre-2.7 aux encoder leaves the bit 0 and the companion
          reads the whole block UNKNOWN (same fail-open as before). No other
          bridge behaviour changed; Catalog.lua revision stays 3.

v2.3:     defensive intelligence. The bridge stages MaxDps's own defensive glow
          colour (vendor Buttons.lua:1056 GlowDefensiveHPMidnight) at the
          curve's control points: HP <=30% Red, <50% Orange, <100% Yellow,

          flagged ready+bound candidate first; when MaxDps names none and the
          observed HP urgency is Red, the catalog's derived per-spec
          defensive list (Major first, immunities excluded) supplies a
          gap-fill candidate and flags the source bit. The urgency block is
          ADDITIVE on the v5 wire (reserved nibbles, version stays 5).
